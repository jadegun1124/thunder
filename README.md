# Thunder

ESA(Electric Smart Automation)의 가정용 전등 브랜드 Thunder(썬더) 소개 페이지와, 같은 사이트 안의 조명 앱 미리보기입니다.

| 화면 | 주소 |
| --- | --- |
| 브랜드 홈 | https://jadegun1124.github.io/thunder/ |
| 앱 미리보기 | https://jadegun1124.github.io/thunder/preview/ |
| ESA | https://jadegun1124.github.io/esa/ |

`main`에 푸시하면 GitHub Actions가 `base` `/thunder/`로 빌드해 GitHub Pages에 올립니다.

미리보기는 방마다 켜기/끄기, 밝기, 장면, 시리·빅스비 호출 예시만 담습니다. 상태는 그 브라우저 탭의 `sessionStorage`에만 있고, 계정·결제·서버는 없습니다. 앱이 마이크를 열어 두고 듣지 않습니다.
