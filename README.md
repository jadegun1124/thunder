# Thunder

ESA 계열 회사 Thunder의 소개 페이지와, 같은 사이트 안의 앱 미리보기입니다.

| 화면 | 주소 |
| --- | --- |
| 회사 홈 | https://jadegun1124.github.io/thunder/ |
| 앱 미리보기 | https://jadegun1124.github.io/thunder/preview |
| ESA | https://jadegun1124.github.io/esa/ |

`main`에 푸시하면 GitHub Actions가 `base` `/thunder/`로 빌드해 GitHub Pages에 올립니다. 회사 홈의 **앱 미리보기**는 `/preview`로 갑니다.

미리보기의 체크는 그 브라우저 탭의 `sessionStorage`에만 있고, 서버로 보내지 않습니다.
